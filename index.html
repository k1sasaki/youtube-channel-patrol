ようつべパトロール

YouTube登録チャンネルの新着動画を、前回確認した時点からの差分だけまとめて見る。データはすべてこの端末のブラウザ内(localStorage)に保存され、外部には送信されません。

APIキー 未設定

Google Cloud Console で YouTube Data API v3 を有効化して取得したAPIキーを入力してください。入力した値はこの端末のlocalStorageにのみ保存され、YouTube(Google)以外へは送信されません。

ブックマークレット

YouTubeでチャンネルページや動画ページを見ているとき、下のリンクをブックマークバーへドラッグして登録しておくと、ワンクリックでそのページの候補を「追加しましたか」欄に持ってこられます(クリックではなく、ドラッグして登録してください)。

新着の点検

「巡回する」を押すと、ここに新着動画がチャンネルごとに表示されます。

見なくなったチャンネルは、YouTube側でも登録解除するのをお忘れなく(ここの「対象外」はこのアプリの巡回対象から外すだけで、YouTube本体には影響しません)。
