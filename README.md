# ようつべパトロール

YouTubeの登録チャンネルは通知が多すぎて確認しきれず、そのまま死蔵しがちです。無限スクロールに飲まれず、前回確認した時点からの新着動画だけをチャンネルごとにまとめて見られる、個人用兼配布用のツールです。

`index.html` 1枚で完結する単体アプリで、サーバもインストールも不要です。ダウンロードしてブラウザで開くだけで動きます。

## できること

- Google Takeoutで書き出した登録チャンネルのCSVを取り込み、巡回対象リストを作る
- チャンネルごとに「最終確認日時」を記録し、それより新しい動画だけを新着として表示
- 巡回対象から外す(YouTube側の登録解除とは別)、一時的に未読へ戻す、といった整理操作
- ブックマークレットで、YouTubeを見ていて気になったチャンネルをその場で候補として持ち込める
- すべてのデータ(APIキー・チャンネルリスト・巡回結果)はブラウザのlocalStorageに保存され、外部には一切送信されません

## 動作環境

- モダンブラウザ(Chrome / Edge / Firefox / Safari)。PCでの利用を想定しています
- スマホでも一応動きますが、CSVの取り込みやブックマークレット登録がやりづらいため、あまりおすすめしません
- サーバ不要。`index.html` を直接開くほか、Webサーバに置いて配信することもできます(その場合もこのファイル単体で動きます)

## 初回セットアップ

### 1. YouTube Data APIキーを取得する

1. [Google Cloud Console](https://console.cloud.google.com) にアクセスし、新しいプロジェクトを作成
2. 「APIとサービス」→「ライブラリ」で **YouTube Data API v3** を検索して有効化
3. 「APIとサービス」→「認証情報」→「認証情報を作成」→「APIキー」でキーを発行
4. 必要なら「キーを制限」で「YouTube Data API v3」のみに絞っておくと安全です

無料枠は1日10,000ユニット。このアプリは1チャンネルの巡回につき1ユニット程度しか消費しないので、数百チャンネル規模でも十分足ります。取得したキーは自分専用です。他人と共有する必要はありません(このアプリは利用者ごとに自分のキーを入力する設計です)。

### 2. 登録チャンネルのCSVを用意する

1. [Google Takeout](https://takeout.google.com) を開き、「すべて選択を解除」→「YouTubeとYouTube Music」だけチェック
2. エクスポートを作成し、ダウンロード
3. 展開したフォルダの中の「登録チャンネル」フォルダにあるCSVファイルを使う

### 3. アプリに読み込ませる

1. `index.html` をブラウザで開く
2. 「APIキー」欄に手順1で取得したキーを入力
3. 「整理しましょう」欄にCSVをドラッグ&ドロップ
4. 「新着の点検」欄の「▶ 巡回する」を押す

## 日常の使い方

- **新着の点検**: 「▶ 巡回する」を押すとチャンネルごとに新着動画がまとまって出ます。もう見ないと思ったチャンネルは、見出しの「対象外」でこのアプリの巡回対象から外せます(YouTube本体の登録解除は別途ご自身で行ってください)
- **整理しましょう**: チャンネル一覧から棚卸しができます。各行に最新投稿のサムネイルが出るので、開かなくても内容を思い出しやすくなっています。登録が増えたら同じCSVを取り直してドロップするだけで、増えた分だけ自動で追加されます(「今回はこのCSVに完全に同期する」にチェックを入れると、CSVに無くなったものを一括で対象外にすることもできます)
- **追加しましたか**: URL・@ハンドル・チャンネルID・動画URLのいずれかを貼り付けて手動追加できます。「APIキー」欄にあるブックマークレットをブックマークバーへドラッグして登録しておくと、YouTubeを見ているときにワンクリックでそのページを候補として持ち込めます

## データとプライバシー

- APIキー・チャンネルリスト・巡回結果は、すべてその端末のブラウザのlocalStorageにのみ保存されます
- 外部のサーバには一切送信されません(通信するのはYouTube Data APIのみ)
- 複数の端末・ブラウザ間でデータは同期されません。別の環境で使う場合は、その都度セットアップし直してください
